# TBot Neon Mochi Faces

21 looping emotion GIFs for the TBot robot LCD — glowing **neon cyan→magenta**
eyes on a pure black background. 320×240, ready to play on an ESP32-S3 LCD or any
GIF viewer.

## Emotions (21)
neutral, happy, laughing, funny, sad, angry, crying, loving, embarrassed,
surprised, shocked, thinking, winking, cool, relaxed, delicious, kissy,
confident, sleepy, silly, confused

## Preview
Open `preview.html` in a browser to see all faces animated, or `preview/contact_sheet.png`.

## Specs
- 320×240, pure black background, ~14 frames/clip, looping GIF
- Total ~3.6 MB
